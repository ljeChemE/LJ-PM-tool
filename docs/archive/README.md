# Archive

**Nothing here describes current state.**

This directory holds completed one-time plans and point-in-time deliverables
— migration plans, cutover runbooks, superseded proposals — kept for the
*rationale* behind decisions now baked into the system. They are stripped of
authority the moment they land here.

Anything operational inside an archived document — a branch name, a "not done
yet" note, a person's role at the time — reflects the tree as it stood the
day it was written. It has almost certainly been superseded since. Treat
every archived doc as a historical artifact, not a reference.

If you need to know what's true **right now**, this is the wrong directory:

- For current design and status, start at [../README.md](../README.md).
- For what's shipped, what's in flight, and what's next, see
  [../Implementation-Plan.md](../Implementation-Plan.md).
